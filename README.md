## Особенности проекта

* **Валидация ссылок:** Проверка вводимых URL на корректность и дубликаты через `Yup`.
* **Автообновление:** Фоновый запрос новых постов каждые 5 секунд без перезагрузки страницы.
* **Архитектура:** Разделение логики и UI по паттерну MVC с помощью `on-change`.
* **Просмотр постов:** Модальное окно с описанием поста и подсветкой уже прочитанных.
* **Мультиязычность:** Перевод интерфейса и ошибок с помощью `i18next`.

## Стек

* **Язык:** JavaScript (ES6+)
* **Сборщик:** Vite
* **Сетевые запросы:** Axios
* **Валидация:** Yup
* **Интернационализация:** i18next
